# Netflix Content Analytics 🍿📊

An exploratory data analysis (EDA) and visualization pipeline designed to uncover trends, content distribution, and strategic insights from Netflix's massive global catalog.

## 🚀 Project Overview

Streaming platforms generate and curate an immense amount of data. Understanding the shift in content strategy—such as the balance between TV Shows and Movies, global rating distributions, and the velocity of new additions—is critical for media analytics.

This project ingests historical data of Netflix's catalog to clean, process, and visually explore the platform's trajectory over time.

## ⚙️ Methodology & Features

1. **Data Cleaning**: Handling missing directors, casting nulls, and standardizing date formats.
2. **Feature Engineering**: Extracting the exact duration (minutes for movies, seasons for TV shows), release years, and parsing complex multi-genre strings.
3. **Exploratory Data Analysis**:
   - Content ratio analysis (Movies vs. TV Shows).
   - Growth trajectory mapping (Titles added per year).
   - Geographic distribution of content creation.
4. **Data Visualization**: Creating rich, interactive charts using Python's visualization libraries to make the data highly digestible.

## 🛠️ Tech Stack & Libraries Used

- **Data Manipulation:** Pandas, NumPy
- **Data Visualization:** Plotly, Seaborn, Matplotlib

## 📈 Key Outcomes

- Revealed the exact timeline where Netflix shifted focus from licensed movies to original TV Shows.
- Identified the top geographic regions contributing to the platform's content library.
